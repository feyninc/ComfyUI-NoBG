# Registry icon

`icon.png` is a square, 400x400 rendition of
[`nobg-logo.png`](https://github.com/feyninc/nobg/blob/main/assets/nobg-logo.png)
from the Apache-2.0-licensed nobg repository, padded with transparency to fit the
registry's icon requirements.

The JPEGs in `example_workflows/` are template-browser title cards. The FeyNobg
card contains the actual output from `tests/run_workflow.py`; the SAM3 card is
an instructional card, not a claim of tested SAM3 inference.
